# Как работает импорт проекта через Share-ссылку

## Автоматический процесс

Когда вы указываете `continue_url` в файле промптов или вводите URL в интерактивном режиме, runner автоматически:

1. **Открывает share-ссылку** на текущем аккаунте
2. **Находит кнопку "Duplicate"** (может называться Fork/Remix)
3. **Кликает на неё** — проект клонируется в ваш аккаунт
4. **Ждёт редирект** на новый URL вашей копии проекта
5. **Продолжает работу** с вашей копией

## Как получить share-ссылку проекта v0

### Вариант 1: Публичная ссылка (рекомендуется)

1. Откройте ваш проект в v0.app
2. Нажмите кнопку **Share** (правый верхний угол)
3. В диалоге выберите **"Anyone with the link"** или **"Public"**
4. Скопируйте ссылку из поля
5. Используйте эту ссылку в `continue_url` или в интерактивном режиме

### Вариант 2: Приватный чат своего аккаунта

Если проект уже принадлежит вашему аккаунту, можно использовать прямой URL:

```
https://v0.app/chat/abc123def456
```

Runner попробует открыть его напрямую. Если не получится (404 или редирект на логин), выдаст ошибку.

## Формат файла с continue_url

```txt
model: Opus 5
trigger: ✅ГОТОВО
retry_prompt: Доделай предыдущий шаг и напиши "{trigger}" когда закончишь.
continue_url: https://v0.app/chat/abc123def456

1) Добавь новую фичу в этот проект
2) Оптимизируй код
```

## Важно

- **Share-ссылка должна быть публичной** (Anyone with the link)
- После Duplicate у вас будет **своя копия проекта** — изменения не затронут оригинал
- Если кредиты закончатся, runner автоматически создаст share-ссылку текущего состояния и продублирует его на следующий аккаунт
- Прогресс сохраняется в `prompts/done/<имя>.progress.json` — можно продолжить позже

## Пример использования

### Интерактивный режим

```powershell
npm start
# Выбираете: "🔗 Продолжить существующий проект"
# Вводите: https://v0.app/chat/abc123def456
# Выбираете модель
# Вводите промпт
```

### Многопромптовый файл

Создайте `prompts/my-task.txt`:

```txt
model: Opus 5
trigger: ✅ГОТОВО
retry_prompt: Доделай и напиши "{trigger}"
continue_url: https://v0.app/chat/abc123def456

1) Добавь темную тему. Напиши "{trigger}" когда готово.
2) Добавь мобильную версию. Напиши "{trigger}" когда готово.
```

Запустите:

```powershell
npm start
# Выбираете: "📋 Многопромптовая цепочка (новый проект)"
# Выбираете файл: my-task.txt
```

Runner автоматически импортирует проект и выполнит все шаги по порядку.
